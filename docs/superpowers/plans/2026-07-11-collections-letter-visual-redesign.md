# Collections Letter Templates — Structural Fix & Visual Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the clause-numbering defects and equipment-table column mismatch in the Equipment Agreement and Employment Agreement PDF generators, and polish both documents' letterhead/table typography to a professional business-letter standard.

**Architecture:** Both documents are generated by two IPC handlers in `src/main/ipc/index.ts` that build an HTML string (rendered to PDF elsewhere) via template literals with inline `<style>` blocks. All changes are edits within these two existing handlers — no new files, no new IPC channels, no schema changes.

**Tech Stack:** TypeScript (Electron main process), inline HTML/CSS template literals, better-sqlite3 (read-only queries already in place).

Replace with a version that splits status text from its date and adds a severity tag, keeping the map and disposition-resolution logic identical:

```typescript
      const statusMap: Record<string, string> = {
        in_use: 'In Use', returned_good: 'Returned', returned_damaged: 'Returned (Damaged)',
        lost: 'Lost', stolen: 'Stolen', not_returned: 'Not Returned', retired: 'Retired',
      };
      const statusSeverity: Record<string, 'high' | 'medium' | 'none'> = {
        in_use: 'none', returned_good: 'none', retired: 'none',
        returned_damaged: 'medium', lost: 'medium',
        stolen: 'high', not_returned: 'high',
      };
      const dispositionInfo = (item: any): { label: string; date: string; severity: 'high' | 'medium' | 'none' } => {
        const d = item.disposition || (item.return_date ? 'returned_good' : 'in_use');
        const label = statusMap[d] || 'In Use';
        const severity = statusSeverity[d] || 'none';
        const dateVal = item.return_date || item.disposition_date;
        const date = (dateVal && d !== 'in_use') ? fmtDate(dateVal) : '—';
        return { label, date, severity };
      };
```

This removes the old `dispositionLabel` function entirely (replaced by `dispositionInfo`) — update every call site in the next steps.
